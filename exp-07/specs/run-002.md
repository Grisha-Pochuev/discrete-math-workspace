# Run 002 — r25 manual matrix

Operational specification only.  This run is prepared but not automatically launched.

## Inputs

```text
engine  = r25
lo      = 12000000000000000001
hi      = 18446744073709551615
chunk   = 100000000000000
seconds = 19800 maximum per worker
parts   = 20
```

The interval contains 64,468 chunks.  Parts 0..7 own 3,224 chunks each; parts 8..19 own 3,223 chunks each.  Ownership is block-cyclic by `chunk_index mod 20`.

## Execution

- One worker process per GitHub-hosted runner.
- Maximum 20 runners in parallel.
- Job timeout 360 minutes.
- `exp-07/run/smoke_r25.sh` must pass before the matrix starts.
- `exp-07/run/r25_job.sh` packages every worker result and encrypts detailed files with `exp-07/k0.pub`.
- A scientific hit exits 10; a soft partial exits 124.  Either prevents the matrix from being treated as a complete negative run while preserving its package when normal packaging succeeds.

## Acceptance and coverage

`exp-07/run/collect_r25.py` independently verifies:

- exactly 20 worker packages with ids 0..19;
- one common source commit and one common parameter set;
- each worker's expected block-cyclic chunk count;
- `assigned == done == expected_chunks` for every worker;
- zero partial flags and zero hits for a negative certificate;
- the 20 expected chunk counts sum to all 64,468 chunks.

Only when all of these checks pass may the interval be recorded as complete negative coverage.
