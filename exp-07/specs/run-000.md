# Run 000

## Execution

- 30 jobs.
- 4 independent single-thread workers per job.
- Six target classes, five jobs per class.
- Shared parameter ceiling: 1100.
- Each worker gets at most 840 seconds of search time.
- Job timeout target: 20 minutes.

## Partition

For each class the 20 CPU workers are numbered 0..19. Worker `k` processes parameter indices congruent to `k mod 20`, in increasing order, and scans the full second-index set for each completed first index.

The worker summary records the exact number of completed assigned indices and the last completed index. A clean time limit preserves partial exact coverage; it must not be reported as full coverage.

## Acceptance

- Exact integer arithmetic decides the multiplicative lookup.
- Floating point is used only as a deliberately loose near-zero prefilter.
- Every retained record is replayed with Python rational arithmetic.
- Any exact survivor is reconstructed into the original nine-variable constraints and independently checked by the six exact sums.

## Smoke

One large CircleCI VM, four workers, small ceiling 100 and at most 30 seconds. Compile the native worker, run all four shards of one class, run the exact verifier, and preserve diagnostics.

## Budget

The full matrix uses at most 30 machines for roughly 14 minutes of search each, plus setup and collection. This is intentionally below the available monthly pool and leaves room for smoke and targeted rescue.

## Artifacts

Per job preserve machine diagnostics, four worker summaries, near-record files, and one exact-verification summary. The collector preserves aggregate counts and any exact survivors.
