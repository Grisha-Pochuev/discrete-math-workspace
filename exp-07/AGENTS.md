# Agent guide

Keep this track isolated from other repository work.

Before changing or launching compute, read the local README, control file, active spec, and latest accepted run summary.

- Use exact checks for acceptance.
- Approximate values may rank records only.
- Do not infer global conclusions from finite coverage.
- Do not repeat archived searches without a documented reason.
- Independently verify accepted records.

Before a large matrix launch, inspect queued and in-progress workflows. Do not overlap large matrices.

A full run requires committed implementation, self-tests, a successful smoke run, explicit enablement, and manual launch.

Preserve compact checksummed coverage and accepted records. Failed shards are missing coverage, not negative results.
