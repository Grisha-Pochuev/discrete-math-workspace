# r34 shared inert-prime support

This note strengthens the inert-prime restriction of `r30` by using the square-norm identity from `r29` and then propagating it across neighboring tiles.

## 1. One tile

For one adjacent cube rectangle, `r29` gives positive integers `u,v,k,n` and

```text
m^2 = uv(u+6k)(v+6k) - 108k^4.
```

Equivalently,

```text
uv(u+6k)(v+6k) = m^2 + 3(6k^2)^2.                (1)
```

Let `ell` be an odd prime with

```text
ell == 2 (mod 3).
```

For such a prime, `-3` is a quadratic nonresidue modulo `ell`.

Suppose `ell` divides one of

```text
u,
v,
u+6k,
v+6k.
```

Then the left side of (1) is zero modulo `ell`.  If `ell` did not divide `k`, division by `(6k^2)^2` in (1) would give

```text
(m/(6k^2))^2 == -3 (mod ell),
```

which is impossible.  Therefore

```text
ell | k.                                          (2)
```

Thus every odd prime `ell == 2 (mod 3)` appearing in **any of the four root gaps of an adjacent cube rectangle** must already divide the local deficit parameter `k=d/6`.

This is stronger than the inward-gap support statement of `r30`: it simultaneously controls both inward gaps `u,v` and both outer gaps `u+6k,v+6k`.

## 2. Propagation across the 3x3 grid

Use the four-tile notation from `r29`:

```text
d=6k0, e=6k1, f=6k2, g=6k3,
```

with positive shared inward gaps `u,v,p,q`.  The four tiles have inward-gap pairs

```text
T00: (u,        v),
T01: (u-6k1,   q),
T10: (p,        v-6k2),
T11: (p-6k3,   q-6k3).
```

The quantity `u` is an inward gap of `T00` and an outer gap of `T01`.  Therefore every odd inert prime dividing `u` divides both local deficit parameters:

```text
ell | u, ell == 2 (mod 3)  =>  ell | gcd(k0,k1).  (3)
```

Likewise,

```text
ell | v  => ell | gcd(k0,k2),
ell | p  => ell | gcd(k2,k3),
ell | q  => ell | gcd(k1,k3),                   (4)
```

for every odd prime `ell == 2 (mod 3)`.

Hence the odd inert-prime support of the four shared gaps is constrained by the edge gcds of the `2x2` deficit matrix:

```text
supp_2mod3(u) subset supp(gcd(k0,k1)),
supp_2mod3(v) subset supp(gcd(k0,k2)),
supp_2mod3(p) subset supp(gcd(k2,k3)),
supp_2mod3(q) subset supp(gcd(k1,k3)).           (5)
```

In particular, if one of these neighboring gcds is `1`, the corresponding shared gap has **no odd prime factor congruent to 2 modulo 3**.

## 3. Interaction with the determinant condition

The same four deficit parameters must also satisfy the strict condition from `r28/r29`

```text
k0*k3 > k1*k2.                                   (6)
```

Thus a candidate must simultaneously realize:

- the strict determinant orientation (6),
- four exact divisor/norm equations from `r29`,
- and the four shared inert-prime support conditions (5).

The support conditions are scale-sensitive and global: they arise precisely because a single integer root gap belongs to two neighboring norm equations with different local `k` values.
