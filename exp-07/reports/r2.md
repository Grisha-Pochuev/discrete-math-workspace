# r2 exact reduction note

This note records an exact simplification of the parameterized A/B branch.  It is deliberately local in scope.

## 1. Relative coordinates

Let

```text
P = 1-u+3u^2
Q = 1+u+3u^2
C = 1-2u-3u^3
D = 1+2u+3u^3
```

with `P^3+Q^3=C^3+D^3`.  Put

```text
a = u/(1+3u^2)
b = 2u+3u^3.
```

Then

```text
P/Q = (1-a)/(1+a),
C/D = (1-b)/(1+b).
```

Eliminating `u` gives the low-degree relation

```text
9 a^3 b^2 + 3 a^3 + 3 a^2 b + 2 a - b = 0.          (1)
```

Conversely, on (1), the old parameter is recovered birationally by

```text
u = a(1+3ab)/(1+3a^2).                               (2)
```

The discriminant of (1), viewed as a quadratic in `b`, is

```text
(1+3a^2)^2 (1-12a^2).
```

Thus the apparently large elimination degrees seen in the old coordinates are not intrinsic to the single A/B identity itself.

Ratio multiplication is also simple in these coordinates: if

```text
r(t)=(1-t)/(1+t),
```

then

```text
r(x)r(y)=r((x+y)/(1+xy)).                             (3)
```

## 2. Difference multiplier

For a centered pair `1-t,1+t`, define

```text
theta(t)=t(3+t^2)/(1+3t^2).
```

This is its third-power difference divided by its third-power sum.  Hence the factor by which the alternative pair changes the difference is

```text
k(u)=theta(b)/theta(a)
    =(3u^2+2)(9u^6+12u^4+4u^2+3)/(27u^4+19u^2+3).
```

Exact factorization gives

```text
k(u)-1 =
 (3u^2-3u+1)(3u^2+3u+1)(3u^4+7u^2+3)
 --------------------------------------------------- .
                 27u^4+19u^2+3
```

Both quadratic factors have discriminant `-3`, so `k(u)>1` for every real `u`.  Thus A expands the pair difference and B contracts it.

## 3. Exact exclusion of ABA

Write

```text
rA=P/Q,   rB=C/D,
fA=(D^3-C^3)/Q^3,
fB=(Q^3-P^3)/D^3.
```

For A, put `x=-log(rA)`.  The transformed quantity has the exact simplification

```text
exp(3x)(fA-1) = 1 - 2(C/P)^3.                         (4)
```

On the physical interval `C>0`, necessarily `0<u<1/2`.  There `rA` is strictly decreasing, while `C/P` is strictly decreasing because

```text
d(C/P)/du =
 -(9u^4-6u^3+3u^2+6u+1)/(3u^2-u+1)^2,
```

and

```text
9u^4-6u^3+3u^2+6u+1
 = 3u^2(3u^2-2u+1)+6u+1 > 0.
```

Therefore the right side of (4) is strictly increasing with `x`.

Now take an ABA ratio triangle with parameters `u,v,w`:

```text
rA(w)=rA(u) rB(v).
```

Since `rB(v)<1`, we have `w>u`.  Applying monotonicity of (4) gives

```text
fA(w) - rB(v)^3 fA(u) > 1-rB(v)^3.                  (5)
```

For B there is a second exact identity

```text
1-rB(v)^3-fB(v) = 2(P(v)^3-C(v)^3)/D(v)^3 > 0,      (6)
```

because

```text
P(v)-C(v)=v(3v^2+3v+1)>0.
```

Combining (5) and (6),

```text
fA(w) > rB(v)^3 fA(u) + fB(v).
```

Hence the outer alternative difference is always strictly larger than the sum of the two inner alternative differences.  Exact cancellation is impossible for ABA.

## 4. Exact exclusion of BBA

Let the two adjacent top differences be positive `D1,D2`; the outer one is `D1+D2`.  In BBA the alternatives are

```text
D1/k1,  D2/k2,  k3(D1+D2),
```

with every `ki>1`.  Therefore

```text
k3(D1+D2)-D1/k1-D2/k2
 = (k3-1)(D1+D2)
   +(1-1/k1)D1
   +(1-1/k2)D2 > 0.
```

So BBA is also impossible.

## 5. Remaining scope

After these exact sign arguments, the only mixed orientation types that can still contain cancellation are

```text
AAB, ABB, BAA, BAB.
```

For AAB, the outer-largest branch is additionally impossible by the same `k>1` argument; only an inner difference can be the largest one.

This matches the earlier four high-degree elimination fronts.  The point of r2 is that two of the six mixed types are now removed by short exact inequalities, and the A/B identity itself has a much smaller birational coordinate model (1).

This note does not make a claim outside this parameterized branch.
