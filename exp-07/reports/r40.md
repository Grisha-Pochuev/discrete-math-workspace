# r40 mean-root ratio ordering

This note couples the two additive integer measures `k` and `m` from `r28` and `r39`.

For a cube-coordinate rectangle `I x J`, the two exact integral representations are

```text
k = integral_I integral_J (1/27)(u+v)^(-5/3) dv du,

m = integral_I integral_J (1/9)(u+v)^(-4/3) dv du.
```

Therefore

```text
m/k
 = 3 * weighted_average((u+v)^(1/3)),             (1)
```

where the positive weight density is proportional to `(u+v)^(-5/3)`.

## 1. Immediate root bounds

If `x` and `w` are the smallest and largest cube roots at the two opposite corners of the rectangle, then every point of the integration rectangle has cube root strictly between them except on its boundary. Hence

```text
3x < m/k < 3w.                                    (2)
```

Equivalently,

```text
x < m/(3k) < w.                                   (3)
```

So `m/(3k)` is an intrinsic rational mean root of the rectangle.

## 2. Monotonicity when a coordinate interval moves right

Fix a column-coordinate interval

```text
J=[C,D], C<D.
```

After first integrating in `v`, define the one-variable densities

```text
K_J(u)
 = (1/18)[(u+C)^(-2/3)-(u+D)^(-2/3)],

M_J(u)
 = (1/3)[(u+C)^(-1/3)-(u+D)^(-1/3)].
```

Their ratio simplifies exactly to

```text
M_J(u)/K_J(u)
 = 6 / [(u+C)^(-1/3)+(u+D)^(-1/3)].               (4)
```

The denominator in (4) is strictly decreasing in `u`, so the ratio is strictly increasing.

Now `m/k` for a full rectangle `I x J` is the `K_J`-weighted average of the increasing function (4) over `I`.  If `I0` lies completely to the left of `I1`, every value of (4) on `I1` is larger than every value on `I0`.  Therefore

```text
(m/k)(I0 x J) < (m/k)(I1 x J).                    (5)
```

By symmetry, the same strict increase holds when `J` is moved right while `I` is fixed.

## 3. The four adjacent tiles

Number the four adjacent rectangles as

```text
0  1
2  3
```

with corresponding positive integers `k0,...,k3` and `m0,...,m3`.

Equation (5) gives the strict grid ordering

```text
m0/k0 < m1/k1,
m0/k0 < m2/k2,
m1/k1 < m3/k3,
m2/k2 < m3/k3.                                   (6)
```

Since all `m_i,k_i` are positive integers, (6) strengthens to four integer cross-product gaps:

```text
m1*k0-m0*k1 >= 1,
m2*k0-m0*k2 >= 1,
m3*k1-m1*k3 >= 1,
m3*k2-m2*k3 >= 1.                                (7)
```

These must hold simultaneously with the two determinant inequalities

```text
k0*k3-k1*k2 >= 1,
m0*m3-m1*m2 >= 1.                                (8)
```

Thus the same four tiles carry two strictly TP2 integer measures, while their quotient is strictly increasing in both coordinate directions.
