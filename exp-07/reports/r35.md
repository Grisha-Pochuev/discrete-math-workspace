# r35 diagonal-sum inert-prime support

This note adds two more controlled linear factors to every adjacent cube rectangle.

## 1. Opposite-pair coordinates

For a positive strictly ordered cube rectangle write

```text
x          y=x+h
z=x+a      w=x+a+h-d
```

with

```text
x^3+w^3 = y^3+z^3,
0<d<min(a,h).
```

Define the sums and differences inside the two equal-sum pairs:

```text
s = x+w,
p = w-x,

t = y+z,
q = z-y.
```

Then

```text
t-s=d.
```

Using

```text
r^3+s^3 = (r+s)((r+s)^2+3(r-s)^2)/4,
```

the cube equality is exactly

```text
s(s^2+3p^2) = t(t^2+3q^2).                       (1)
```

## 2. Inert primes cannot occur on only one side

Let `ell` be an odd prime with

```text
ell == 2 (mod 3).
```

Suppose `ell | s` but `ell` does not divide `t`.  Reducing (1) modulo `ell` gives

```text
t(t^2+3q^2) == 0 (mod ell),
```

hence

```text
t^2 == -3q^2 (mod ell).
```

If `q` were zero modulo `ell`, this would force `t` to be zero, contrary to the assumption.  Otherwise `-3` would be a quadratic residue modulo `ell`, impossible for `ell == 2 (mod 3)`.

Therefore

```text
ell | s  => ell | t.
```

By symmetry,

```text
ell | t  => ell | s.
```

Since `t-s=d`, every such prime must divide `d`:

```text
ell | s*t, ell == 2 (mod 3), ell odd
       => ell | d.                                (2)
```

With `d=6k`, this is equivalently

```text
supp_2mod3(s*t) subset supp(k).                   (3)
```

## 3. Relation to the r29 variables

In `r29`, with

```text
d=6k,
u=a-d,
v=h-d,
n=x+3k,
```

the two opposite-pair sums are

```text
s = 2n+u+v,
t = 2n+u+v+6k.                                  (4)
```

The second one is exactly the factor called `T` in the divisor equation

```text
uv*T = 6k(n^2+3k^2).
```

Thus `r30` controls the inert-prime support of `u,v,T`, `r34` controls the four root gaps

```text
u,v,u+6k,v+6k,
```

and the present lemma additionally controls

```text
T-6k, T.
```

Combining them, every odd prime `ell == 2 (mod 3)` dividing any of the six natural positive linear quantities

```text
u,
v,
u+6k,
v+6k,
2n+u+v,
2n+u+v+6k
```

must divide the local parameter `k`.                            (5)

For `k=1`, all six quantities are therefore composed only of the primes `2,3` and primes congruent to `1 (mod 3)`.

This is an exact local obstruction and does not use a finite size bound.
