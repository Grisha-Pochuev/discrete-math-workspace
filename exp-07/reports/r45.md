# r45 symmetric Markoff-grid reduction

This note rewrites every adjacent equal-sum cube rectangle in a symmetric homogeneous form and then records the exact linear gluing of the four rectangles in the `3x3` grid.

## 1. One rectangle

Use the `r27` local notation

```text
x        x+h
x+a      x+a+h-6k
```

with

```text
x>0,
a>6k,
h>6k,
k>0.
```

Define the centered integers

```text
C = 2x+a+h-3k,
P = a-3k,
Q = h-3k.                                        (1)
```

Then automatically

```text
C>3k,
P>3k,
Q>3k.                                            (2)
```

Direct expansion factors the cube-rectangle residual as

```text
x^3+(x+a+h-6k)^3-(x+h)^3-(x+a)^3

 = (3/2) [
   2CPQ-3k(C^2+P^2+Q^2+3k^2)
   ].
```

Hence the local cube equality is equivalent to the symmetric cubic equation

```text
2CPQ = 3k(C^2+P^2+Q^2+3k^2).                    (3)
```

This is a homogeneous Markoff/Fricke-type cubic surface in the four integers `C,P,Q,k`.

After dividing by `k^3` formally and putting

```text
X=C/(3k), Y=P/(3k), Z=Q/(3k),
```

the shape equation is

```text
2XYZ = X^2+Y^2+Z^2+1/3,                          (4)
```

with

```text
X,Y,Z>1.
```

## 2. The square-deficit invariant

The positive integer `m` of `r39` has the exceptionally simple expression

```text
m = 3kC-PQ.                                      (5)
```

The physical branch `m>0` is therefore

```text
3kC>PQ.                                          (6)
```

If (3) is viewed as a quadratic equation in `C`, the other Vieta root is

```text
C'=(P^2+Q^2+3k^2)/C
   =2PQ/(3k)-C.                                  (7)
```

Under this involution

```text
3kC'-PQ = -m.                                    (8)
```

Thus the two quadratic branches are exactly the positive-`m` and negative-`m` branches.  The physical cube rectangle selects the larger root in the `C` direction.

Equation (5) also gives the equivalent square relation

```text
m^2
 = P^2 Q^2-9k^2(P^2+Q^2+3k^2),                 (9)
```

or

```text
(P^2-9k^2)(Q^2-9k^2)=m^2+108k^4,                (10)
```

which is the `r39` side-product identity because

```text
P^2-9k^2=a(a-6k),
Q^2-9k^2=h(h-6k).
```

## 3. Four adjacent tiles

Use the arrangement

```text
0  1
2  3
```

and write their invariants as

```text
(Ci,Pi,Qi,ki),  i=0,1,2,3.
```

Every tile separately satisfies (3) and (2).

The common root-grid gluing becomes linear:

```text
P1 = P0-3(k0+k1),
P3 = P2-3(k2+k3),                                (11)

Q2 = Q0-3(k0+k2),
Q3 = Q1-3(k1+k3),                                (12)
```

and

```text
C1 = C0+Q0+Q1,
C2 = C0+P0+P2,
C3 = C1+P1+P3
   = C2+Q2+Q3.                                   (13)
```

So the full problem can be viewed as four integer points on the single symmetric cubic surface (3), tied together by the linear relations (11)-(13), with all twelve centered shape coordinates strictly larger than the corresponding `3ki`.

This removes the absolute root `x` and the asymmetric local variables from the four nonlinear equations simultaneously.
