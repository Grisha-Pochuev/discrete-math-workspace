# r36 root-gap total positivity

This note gives four new strict global inequalities for the ordered `3x3` root grid of `r27`.  They are independent of the mixed-deficit determinant `d*g>e*f` from `r28`.

## 1. Root gaps as integrals

Write the cube-value grid in the universal Cartesian form

```text
Ai+Bj
```

and its positive cube roots as

```text
r_ij = F(Ai+Bj),
F(t)=t^(1/3).
```

For a vertical cube-coordinate interval `I=[A_i,A_{i+1}]`, the corresponding root gap at column coordinate `B` is

```text
G_I(B)=integral_I F'(u+B) du,
F'(t)=(1/3)t^(-2/3).
```

Let `I0` lie strictly to the left of `I1`, and let `B0<B1`.  For

```text
u in I0,
U in I1,
```

we have

```text
(u+B0)(U+B1) < (u+B1)(U+B0),
```

because the difference of the right side and left side is

```text
(U-u)(B1-B0)>0.
```

Raising the positive products to the power `-2/3` reverses the product comparison.  Therefore

```text
F'(u+B0)F'(U+B1)
  > F'(u+B1)F'(U+B0).
```

Integrating over `I0 x I1` gives the strict `TP2` inequality

```text
G_I0(B0) G_I1(B1)
  > G_I0(B1) G_I1(B0).                           (1)
```

The same argument applies after interchanging the two coordinate directions.

## 2. Vertical root-gap matrix

In the `r27` variables the vertical root gaps are

```text
[ a,       a-d,       a-d-e ]
[ b,       b-f,       b-f-g ].
```

Applying (1) to the first two columns and then the last two columns gives

```text
a(b-f) > b(a-d),
(a-d)(b-f-g) > (b-f)(a-d-e).
```

After cancellation:

```text
b*d > a*f,                                        (2)
(b-f)*e > (a-d)*g.                                (3)
```

## 3. Horizontal root-gap matrix

Likewise the horizontal root gaps are

```text
[ h,       j       ]
[ h-d,     j-e     ]
[ h-d-f,   j-e-g   ].
```

The two adjacent minors give

```text
h(j-e) > j(h-d),
(h-d)(j-e-g) > (j-e)(h-d-f),
```

or equivalently

```text
j*d > h*e,                                        (4)
(j-e)*f > (h-d)*g.                                (5)
```

Thus all four required strict inequalities are

```text
b*d > a*f,
(b-f)*e > (a-d)*g,
j*d > h*e,
(j-e)*f > (h-d)*g.                                (6)
```

## 4. Integer strengthening

By `r27`,

```text
d=6k0, e=6k1, f=6k2, g=6k3.
```

Hence each positive determinant in (6) is a positive multiple of 6.  In particular

```text
b*k0-a*k2 >= 1,
(b-6k2)*k1-(a-6k0)*k3 >= 1,
j*k0-h*k1 >= 1,
(j-6k1)*k2-(h-6k0)*k3 >= 1.                      (7)
```

Equivalently, the successive contraction ratios of the root gaps obey

```text
(a-d)/a < (b-f)/b,
(a-d-e)/(a-d) < (b-f-g)/(b-f),
(h-d)/h < (j-e)/j,
(h-d-f)/(h-d) < (j-e-g)/(j-e).                   (8)
```

These inequalities are strict consequences of the cube-root kernel itself; they do not come from checking the four adjacent rectangle equations separately.
