# r42 power-deficit determinant hierarchy

This note attaches several independent integer `2x2` determinant conditions to the same four adjacent rectangles of the universal cube grid.

## 1. Mixed root-power measures

At cube-value level write

```text
r_ij=(Ai+Bj)^(1/3).
```

For an adjacent cube-coordinate rectangle `I x J` and an integer root power `q`, put

```text
Fq(t)=t^(q/3).
```

For `q<3`, `Fq` is concave and we use the positive mixed deficit

```text
Delta_q = r01^q+r10^q-r00^q-r11^q.
```

For `q>3`, `Fq` is convex and we use

```text
Delta_q = r00^q+r11^q-r01^q-r10^q.
```

Every `Delta_q` is an integer because all roots are integers.  It has the exact double-integral representation with positive density proportional to

```text
(u+v)^(q/3-2).                                    (1)
```

The constant multiplier depends only on `q` and does not affect determinant signs.

For the already studied cases,

```text
Delta_1=d=6k,
Delta_2=2m.                                       (2)
```

## 2. Pointwise determinant sign

For `u<U` and `v<V`,

```text
(u+v)(U+V) < (u+V)(U+v).                         (3)
```

Let

```text
beta=q/3-2.
```

If `beta<0`, raising (3) to the power `beta` reverses the inequality, so the density kernel is strictly `TP2`.  If `beta=0`, the kernel is constant.  If `beta>0`, the inequality keeps its direction and the kernel is strictly reverse-`TP2`.

Therefore the `2x2` matrix formed by the four adjacent positive measures `Delta_q` has determinant sign

```text
> 0  for q=1,2,4,5,
= 0  for q=6,
< 0  for every integer q>6.                      (4)
```

The strict inequalities follow after integrating the pointwise determinant over the four Cartesian interval products, exactly as in `r28/r39`.

## 3. New integer determinants

Let the four adjacent `q`-power deficits be

```text
Pq0 Pq1
Pq2 Pq3.
```

Then, in addition to the known cases `q=1` and `q=2`, every candidate must satisfy

```text
P40*P43-P41*P42 >= 1,
P50*P53-P51*P52 >= 1.                             (5)
```

For every integer `q>6`, positivity of the four cell measures and the reverse sign give

```text
Pq1*Pq2-Pq0*Pq3 >= 1.                            (6)
```

Thus one candidate root grid must realize an entire sequence of integer determinant inequalities whose sign changes exactly at power `6`.

## 4. The rigid power-6 boundary

Since

```text
r^6=(r^3)^2,
```

and a cube-value rectangle can be written as

```text
A          A+R
A+C        A+R+C,
```

the power-6 mixed deficit factors exactly as

```text
Delta_6=2*R*C.                                    (7)
```

Hence the four adjacent power-6 deficits form an outer-product matrix

```text
2 * [R0,R1]^T [C0,C1],
```

so their determinant is identically zero, not merely nonpositive.

This gives a natural arithmetic boundary between the four strictly positive-determinant measures at powers `1,2,4,5` and all the reverse-determinant measures above power `6`.
