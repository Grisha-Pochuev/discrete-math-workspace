# r41 coordinate-difference inert-prime support

This note connects the global `k`-gcd restrictions from `r38` directly to the six repeated cube differences in the universal additive-grid form `r20/r22`.

## 1. Inert primes in a difference of two cubes

Let `ell` be an odd prime with

```text
ell == 2 (mod 3).
```

Since `gcd(3,ell-1)=1`, the cube map is a bijection on the nonzero residue classes modulo `ell`. Hence

```text
Y^3 == X^3 (mod ell)  =>  Y == X (mod ell).       (1)
```

So

```text
ell | (Y^3-X^3)  =>  ell | (Y-X).                (2)
```

There is also an exact valuation formula. Write

```text
r=min(v_ell(X),v_ell(Y)).
```

Factoring

```text
Y^3-X^3=(Y-X)(Y^2+XY+X^2)
```

and removing `ell^r` from `X,Y`, the second factor has no further factor `ell`: otherwise a nontrivial cube root of unity would exist modulo `ell`. Therefore

```text
v_ell(Y^3-X^3)
 = v_ell(Y-X)+2 min(v_ell(X),v_ell(Y)).            (3)
```

In particular

```text
v_ell(Y^3-X^3) == v_ell(Y-X) (mod 2).             (4)
```

## 2. Six coordinate differences

By `r20`, write the nine cube values as

```text
Ai+Bj,   i,j in {0,1,2},
```

with `A0<A1<A2` and `B0<B1<B2`. Define

```text
RA=A1-A0,
SA=A2-A1,
TA=A2-A0=RA+SA,

RB=B1-B0,
SB=B2-B1,
TB=B2-B0=RB+SB.                                  (5)
```

By `r22`, each of these six positive integers is represented as a difference of positive cubes in at least three ways.

Use the `r27` deficit parameters

```text
d=6k0, e=6k1, f=6k2, g=6k3.
```

The three root gaps realizing `RA` are

```text
a,
a-d,
a-d-e.
```

If an odd inert prime `ell` divides `RA`, (2) says that `ell` divides all three of these root gaps. Applying `r38` gives

```text
ell | RA  => ell | gcd(k0,k1).                   (6)
```

The same argument for the other five coordinate differences yields

```text
ell | SA  => ell | gcd(k2,k3),
ell | TA  => ell | gcd(k0+k2,k1+k3),

ell | RB  => ell | gcd(k0,k2),
ell | SB  => ell | gcd(k1,k3),
ell | TB  => ell | gcd(k0+k1,k2+k3).             (7)
```

Thus the odd prime support congruent to `2 modulo 3` of each repeated cube difference is contained in one explicit gcd of the four deficit parameters.

## 3. Immediate primitive consequences

For example,

```text
gcd(k0,k1)=1
```

forces `RA` to have no odd prime factor congruent to `2 modulo 3`. Likewise each of the other five gcds in (7) being `1` removes that inert-prime class from the corresponding repeated cube difference.

More generally, if `G_A01=gcd(k0,k1)`, then

```text
supp_{ell == 2 mod 3}(RA) subset supp(G_A01),
```

and analogously for all six coordinate differences.

Equation (3) adds a parity refinement: for every one of the three root-gap representations of a fixed coordinate difference, its `ell`-adic valuation has the same parity as the valuation of that coordinate difference. This recovers the strip-parity phenomenon of `r37` directly from the repeated-difference coordinates.

The result is universal and contains no finite-search assumption.
