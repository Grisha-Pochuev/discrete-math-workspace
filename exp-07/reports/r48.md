# r48 fixed-layer genus-10 closure curve

This note reformulates the search for additional layers above one fixed base triple as an arithmetic problem on a single projective curve.

## 1. Fix one base layer

Take three distinct positive rational roots

```text
a<b<c
```

and put

```text
A=b^3-a^3,
B=c^3-a^3.
```

Thus

```text
A>0,
B>A,
B-A=c^3-b^3>0.
```

A second layer `(p,q,r)` has exactly the same two transverse cube differences iff

```text
q^3-p^3=A,
r^3-p^3=B.                                       (1)
```

Projectivizing with a coordinate `T` gives the curve

```text
C_{A,B}:
Q^3-P^3=A T^3,
R^3-P^3=B T^3                                   (2)
```

in `P^3`.

The original base layer gives the rational point

```text
[P:Q:R:T]=[a:b:c:1].                             (3)
```

Every additional rational point with `T!=0`, positive affine coordinates, and distinct coordinates gives another rational layer.  A full semimagic cube grid with this fixed base layer requires two suitable nontrivial additional rational points on the same curve.

Because all equations are homogeneous, clearing denominators of the three layers produces integer roots.  Hence a positive rational closure is already enough for the original integer problem.

## 2. Smoothness

Let

```text
F1=Q^3-P^3-A T^3,
F2=R^3-P^3-B T^3.
```

Their gradients, after removing the common factor 3, are

```text
grad F1=(-P^2, Q^2, 0, -A T^2),
grad F2=(-P^2, 0, R^2, -B T^2).                 (4)
```

Suppose they were linearly dependent at a projective point of (2).

If `Q` and `R` are both nonzero, the `Q` and `R` coordinates of (4) immediately force both coefficients of the dependence to vanish.

If `Q=0`, then the first equation gives

```text
P^3=-A T^3.
```

A projective point cannot have `T=0`, so `P,T` are nonzero.  The second equation then gives

```text
R^3=(B-A)T^3,
```

and `R` is nonzero because `B!=A`.  The `R` and `P` gradient coordinates again force the dependence coefficients to vanish.  The case `R=0` is symmetric.  The case `Q=R=0` would force `(A-B)T^3=0`, and hence the zero projective point, impossible.

Thus `C_{A,B}` is a smooth complete intersection of two cubics in `P^3`.

## 3. Genus

For a smooth complete intersection of degrees `d,e` in `P^3`, adjunction gives

```text
2g-2 = d*e*(d+e-4).
```

Here `d=e=3`, so

```text
2g-2=3*3*2=18,
g=10.                                              (5)
```

So fixing only one base layer has already converted the closure problem into the rational-point problem on a genus-10 curve.

## 4. Generalized Fermat identification

Over an algebraic closure choose a cube root `rho` with

```text
rho^3=A.
```

Set

```text
x1=rho*T,
x2=P,
x3=-Q,
x4=-R.
```

Then (2) becomes

```text
x1^3+x2^3+x3^3=0,
(B/A) x1^3+x2^3+x4^3=0.                           (6)
```

Thus `C_{A,B}` is a rational diagonal twist of the generalized Fermat curve of type `(3,3)` with parameter

```text
lambda=B/A.                                       (7)
```

Carvacho--Hidalgo--Quispe treat exactly the model (6): it has genus 10 and its Jacobian decomposes, up to isogeny, into four elliptic quotients and three genus-2 quotients; those genus-2 Jacobians themselves split into elliptic factors.  Consequently the genus-10 Jacobian is completely decomposable into elliptic curves.  The later general decomposition theorem of Martinez-Nunez records the same type `(3,3)` case as a product of 10 elliptic curves.

Important arithmetic caution: those papers formulate the decomposition over the complex numbers.  Our curve is a `Q`-twist, so the ten factors need not all be the same elliptic curve over `Q`; the rational twists and descent fields must be tracked explicitly before using the decomposition for rational points.

## 5. Four elliptic quotients already defined over Q

Three quotient cubics are immediate from (2):

```text
E_A:     Q^3-P^3=A T^3,
E_B:     R^3-P^3=B T^3,
E_BA:    R^3-Q^3=(B-A)T^3.                       (8)
```

The fourth follows by eliminating `T`:

```text
B Q^3-A R^3+(A-B)P^3=0.                          (9)
```

Each is a smooth plane cubic because `A`, `B`, and `B-A` are nonzero, and each receives a rational point from the base layer.  Hence all four are elliptic curves over `Q` after choosing the base point as origin.

For a difference cubic

```text
y^3-x^3=D
```

the affine birational map

```text
X=12D/(y-x),
Y=36D(y+x)/(y-x)                                  (10)
```

lands on the `j=0` Mordell curve

```text
Y^2=X^3-432D^2.                                   (11)
```

So the first three elliptic factors in (8) are explicit Mordell twists for

```text
D=A,
D=B,
D=B-A.
```

The fourth diagonal cubic (9) is also an elliptic curve over `Q`, but its convenient Weierstrass model depends on the chosen rational base point `(a,b,c)`.

## 6. Consequence for the next step

Blindly enumerating rational points on (2) is a genus-10 problem and is therefore a poor default strategy.  The relevant arithmetic object has much more structure:

- four explicit elliptic quotient maps are already defined over `Q`;
- the complex Jacobian has six further elliptic dimensions coming from three genus-2 quotients;
- the base layer gives a known rational point on every quotient;
- a nontrivial layer must map to a mutually compatible tuple of elliptic points.

The next useful target is therefore to descend the remaining six factors to explicit elliptic twists over `Q` (or a controlled quadratic extension) and determine whether the compatibility conditions can be reduced to ranks / Selmer conditions on those elliptic curves.
