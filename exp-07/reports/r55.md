# r55 — cyclic cubic cover and exact rational-orbit search

This note recasts the fixed-layer genus-10 problem of `r48` as a cubic-value condition on one elliptic curve and records an exact rational search that is not bounded by the eventual integer root size.

## 1. The base elliptic curve

For a fixed positive base triple

```text
a<b<c
```

put

```text
A=b^3-a^3,
B=c^3-a^3,
lambda=B/A > 1.
```

A rational triple `(P,Q,R)` has the same transverse *ratio* as the base layer iff

```text
R^3-P^3 = lambda (Q^3-P^3),
```

or projectively

```text
E_lambda:
(lambda-1)P^3-lambda Q^3+R^3=0.                 (1)
```

This is a smooth diagonal plane cubic.  It contains the universal rational point

```text
O=[1:1:1],                                       (2)
```

so choosing `O` as origin makes `E_lambda` an elliptic curve over `Q`.

The original base triple and every translated layer lie on the same curve.

## 2. The genus-10 curve is a three-sheeted cubic cover

Let

```text
Delta(P,Q,R)=Q^3-P^3.
```

A projective rational point of `E_lambda` can be rescaled to a layer having the *same* first transverse difference `A` exactly iff

```text
Delta/A is a rational cube.                      (3)
```

Introduce a projective scaling coordinate `T`.  Equation (3) is

```text
Q^3-P^3=A T^3.                                   (4)
```

Together with (1), it forces

```text
R^3-P^3=B T^3.                                   (5)
```

Thus (4)-(5) are precisely the fixed-layer complete intersection `C_{A,B}` of `r48`.  The map

```text
pi:C_{A,B} -> E_lambda,
[P:Q:R:T] |-> [P:Q:R]                            (6)
```

is a cyclic degree-3 cover over `Q(omega)`.

The branch points are the zeros of `Delta` on `E_lambda`.  Over the algebraic closure,

```text
Q^3=P^3
```

forces from (1)

```text
R^3=P^3,
```

so the nine branch points are

```text
[1:zeta:eta],   zeta^3=eta^3=1.                 (7)
```

They are simple: each line `Q=zeta P` meets the diagonal cubic transversely at its three points (the `R`-gradient is nonzero there).

Riemann-Hurwitz therefore gives

```text
2g(C)-2 = 3(2*1-2) + 9(3-1) = 18,
g(C)=10.                                         (8)
```

This rederives the genus in `r48` directly from the cubic-cover structure.

Arithmetic interpretation: rational points of the genus-10 cover are exactly rational points of `E_lambda` for which the homogeneous cubic value `Delta` lies in the fixed rational cube class `A*Q^{*3}`.

## 3. Exact group law without a rational flex

A rational flex is not required to work directly on (1).  Use the ordinary point `O=(1:1:1)` as group identity.

For two points `P,Q` on a smooth plane cubic, let `third(P,Q)` be the third intersection with their chord (or tangent when `P=Q`).  If

```text
R=third(P,Q),
S=third(R,O),
```

then divisor subtraction of the two line sections gives

```text
[P-O]+[Q-O]=[S-O].                                (9)
```

Hence

```text
P+Q=S.                                            (10)
```

All chord/tangent intersections for the diagonal cubic are rational operations.  `src/r55_orbit.py` implements them with Python `Fraction`, so no floating approximation is used.

## 4. Orbit attached to a known two-layer strip

Suppose a repeated difference already gives two layers

```text
P0=(a,b,c),
P1=(A0,B0,C0)
```

with the same two transverse differences.  On `E_lambda` put

```text
T=P1-P0.                                          (11)
```

Every point

```text
Pn=P0+nT                                          (12)
```

is rational.  If for some `n != 0,1`

```text
Delta(Pn)/Delta(P0) in Q^{*3}                    (13)
```

and `Pn` has a positive representative, then rescaling `Pn` by the rational cube root in (13) gives an exact third layer.  Clearing denominators of the three layers then gives a full integer candidate.

Crucially, the size of those final integer roots is *unbounded* by this test.  This searches rational closures that a finite scan in `D` or in root height can miss.

## 5. Exact bounded-input / unbounded-output audit

Use the 4,441 two-layer triples independently enumerated in `r54` from all positive cube differences with lower/upper roots at most 15,000.

For every strip, `src/r55_orbit.py`:

1. reconstructs `lambda` exactly;
2. verifies `P0,P1` lie on (1);
3. computes `T=P1-P0` by exact chord/tangent arithmetic;
4. walks the orbit (12);
5. tests the rational cube class (13) by exact integer cube roots of the reduced numerator and denominator.

The run

```text
n=-3..4, excluding 0,1
```

checked

```text
4,441 strips,
26,646 nontrivial rational points,
0 cube-class repetitions,
0 positive third-layer hits.
```

An extended run

```text
n=-4..5, excluding 0,1
```

checked

```text
35,528 nontrivial rational points,
0 cube-class repetitions,
0 positive third-layer hits.
```

The second run completed locally in about 24 seconds.  A wider attempted range was stopped by growth of exact rational heights and is not counted as a result.

This is finite evidence, not a proof.  It is nevertheless qualitatively different from the earlier integer scans because the rational points themselves may have arbitrarily large denominators and hence may clear to integer roots far beyond the input bound.

## 6. New theoretical target

The original closure question for a fixed base layer is now the explicit elliptic-value problem

```text
P in E_lambda(Q),
Delta(P)/A in Q^{*3}.                             (14)
```

This suggests three standard arithmetic attacks:

- a 3-descent/Kummer analysis of the cubic value `Delta`;
- elliptic Chabauty on the degree-3 cover (6);
- primitive-divisor / elliptic-divisibility arguments along cyclic subgroups such as (12).

The branch divisor (7) is exceptionally explicit: nine simple points arranged as the intersections `P^3=Q^3=R^3`.  Any successful 3-descent can therefore be written directly in terms of the three linear factors of `Q^3-P^3` over the Eisenstein field.

Exact orbit implementation: `exp-07/src/r55_orbit.py`.
