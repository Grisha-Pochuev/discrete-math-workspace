# r30 inert-prime restriction

This note extracts a prime-support condition from the exact divisor equation in `r29`.  No finite search is involved.

For one adjacent rectangle use

```text
uv(2n+u+v+6k) = 6k(n^2+3k^2),                   (1)
```

with positive integers `n,k,u,v` and `n>3k`.  Put

```text
T = 2n+u+v+6k.
```

Then

```text
uvT = 6k(n^2+3k^2).                              (2)
```

## 1. The quadratic norm

Let `omega` satisfy

```text
omega^2+omega+1=0.
```

The Eisenstein norm is

```text
Norm(A+B*omega)=A^2-A*B+B^2.
```

Taking

```text
A=n+k,
B=2k
```

gives exactly

```text
n^2+3k^2 = Norm((n+k)+2k*omega).                 (3)
```

Thus primes `p == 2 (mod 3)` are the inert prime class for the nontrivial norm factor in (2).

## 2. Exact valuation at inert odd primes

Let `p` be an odd prime with

```text
p == 2 (mod 3).
```

Then `-3` is not a quadratic residue modulo `p`.  Indeed quadratic reciprocity gives

```text
(-3|p) = (p|3) = -1.
```

Write

```text
r = min(v_p(n), v_p(k)),
n = p^r n0,
k = p^r k0,
```

where at least one of `n0,k0` is not divisible by `p`.  Then

```text
n^2+3k^2 = p^(2r) (n0^2+3k0^2).
```

The last factor is not divisible by `p`:

- if `k0` is a unit modulo `p`, divisibility would give `(n0/k0)^2 == -3 (mod p)`, impossible;
- if `k0` is divisible by `p`, then `n0` is a unit and the last factor is `n0^2 != 0 (mod p)`.

Therefore

```text
v_p(n^2+3k^2) = 2 min(v_p(n),v_p(k)).            (4)
```

Taking `p`-adic valuations in (2) gives the exact law

```text
v_p(u)+v_p(v)+v_p(T)
 = v_p(k) + 2 min(v_p(n),v_p(k)).                 (5)
```

## 3. Immediate consequences

If

```text
p does not divide k,
```

then the right side of (5) is zero.  Hence

```text
p does not divide u,
p does not divide v,
p does not divide T.                              (6)
```

So every odd prime factor `p == 2 (mod 3)` appearing in either inward gap must also divide the local deficit parameter `k=d/6`.

If additionally

```text
gcd(n,k)=1,
```

then for every odd `p == 2 (mod 3)` the total exponent of `p` across the three factors `u,v,T` is exactly its exponent in `k`:

```text
v_p(uvT)=v_p(k).                                  (7)
```

This gives an exact prime-support sieve for the divisor classification in `r29`, especially when `k` has few inert-prime factors.

## 4. Four-tile use

Apply (5) independently to the four `r29` tiles.  Their inward-gap pairs are

```text
(u,        v),
(u-6k1,   q),
(p,        v-6k2),
(p-6k3,   q-6k3).
```

Thus any odd inert prime appearing in one of these eight positive inward gaps must be accounted for by the corresponding local `k` through (5).  This condition is independent of the determinant restriction

```text
k0*k3-k1*k2 >= 1
```

from `r28/r29`, so the two filters can be combined in the next arithmetic step.
