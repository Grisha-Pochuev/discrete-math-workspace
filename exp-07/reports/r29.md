# r29 divisor reduction

This note refines the exact root-grid equations from `r27` without making any finite-search claim.

## 1. One adjacent rectangle

Use the `r27` notation

```text
x          x+h
x+a        x+a+h-d
```

with positive integers and

```text
0 < d < min(a,h).
```

The cube rectangle condition is

```text
x^3 + (x+a+h-d)^3 = (x+h)^3 + (x+a)^3.          (1)
```

Put the two positive inward gaps

```text
u = a-d,
v = h-d.
```

Exact expansion turns (1) into

```text
3uv(2x+a+h) = d(3x^2+3dx+d^2).                  (2)
```

By `r27`, every integer cube rectangle has

```text
d = 6k,   k in Z_{>0}.
```

Now center the absolute root by

```text
n = x + d/2 = x+3k.
```

Then (2) becomes the particularly simple integer equation

```text
uv(2n+u+v+6k) = 6k(n^2+3k^2).                   (3)
```

No square root or floating-point quantity occurs in (3).

## 2. Divisor classification for a fixed center

For fixed positive integers `n,k`, equation (3) implies

```text
uv | 6k(n^2+3k^2).                               (4)
```

If

```text
P = uv,
N = 6k(n^2+3k^2),
```

then the sum of the inward gaps is forced to be

```text
u+v = N/P - 2n - 6k.                             (5)
```

Therefore every rectangle with fixed `n,k` is recovered from a positive divisor `P` of `N` for which the right side of (5) is positive and

```text
(u+v)^2 - 4P
```

is a nonnegative perfect square of the correct parity.  The two roots of

```text
t^2 - (u+v)t + P = 0
```

then give `u,v` (up to swapping).

Thus a single exact cube rectangle has a finite divisor classification once `n,k` are fixed.

The factor

```text
n^2+3k^2
```

is a quadratic norm form, which suggests that prime splitting in the `-3` quadratic/Eisenstein setting may be useful for the next arithmetic step.

## 3. Equivalent square identity

Define

```text
m = 6kn - uv.
```

Equation (3) is equivalent to

```text
m^2 = uv(u+6k)(v+6k) - 108k^4.                  (6)
```

In the original variables,

```text
m = d(x+a+h-d/2)-ah.
```

The positive-root branch is forced.  Indeed, since `u+v>0`, (3) gives

```text
uv < 3k(n^2+3k^2)/(n+3k).
```

Because `x>0` means `n>3k`, the right side is strictly smaller than

```text
3k(n-k).
```

Hence

```text
uv < 3k(n-k),
m  = 6kn-uv > 3k(n+k) > 0,                      (7)
```

and in particular

```text
m-uv > 6k^2.                                     (8)
```

This removes the sign ambiguity present in a bare discriminant-square test.

## 4. Four-tile compatibility

For the full ordered `3x3` root grid, write

```text
d=6k0, e=6k1, f=6k2, g=6k3,
```

and use inward gaps

```text
u=a-d,
v=h-d,
p=b-f,
q=j-e.
```

The four adjacent rectangles have inward-gap pairs

```text
(u,        v),
(u-6k1,   q),
(p,        v-6k2),
(p-6k3,   q-6k3),
```

with all displayed quantities positive.

Let `n0,n1,n2,n3` be the centered roots `X+3k` for these four rectangles.  Their locations in the common root grid force

```text
n1 = n0 + v + 3(k0+k1),
n2 = n0 + u + 3(k0+k2),
n3 = n0 + u+v + 3(k0+k3).                        (9)
```

Equivalently,

```text
n3+n0-n1-n2 = 3(k3-k0-k1-k2).                   (10)
```

Each of the four tiles must independently satisfy (3), with its own `n,k` and inward-gap pair, while the four centers must satisfy (9).

## 5. Global determinant condition

The strict determinant inequality from `r28`

```text
dg > ef
```

becomes

```text
k0*k3 > k1*k2.                                   (11)
```

Since the `k` variables are positive integers,

```text
k0*k3-k1*k2 >= 1.                                (12)
```

The result is an entirely integral compatibility system: four divisor/norm equations (3), three linear center relations (9), positivity of the inward gaps, and the strict determinant condition (12).
