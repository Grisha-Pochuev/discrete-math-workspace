# r27 root-grid reduction

This note gives an exact integer-root formulation of the universal additive-grid reduction from `r20`.

## 1. One cube rectangle

Write four positive roots as

```text
x          x+h
x+a        x+a+h-d
```

with `a,h>0` and, for a strictly increasing rectangle, `0<d<min(a,h)`.
The condition that the four cube values form an additive rectangle is

```text
x^3 + (x+a+h-d)^3 = (x+h)^3 + (x+a)^3.          (1)
```

Equation (1) is equivalent to

```text
d [3(x+a+h)^2 - 3d(x+a+h) + d^2]
   = 3ah(2x+a+h).                                (2)
```

As a quadratic equation in `x`, its discriminant is exactly

```text
Delta = 3 [12ah(a-d)(h-d) - d^4].                (3)
```

Hence every integer rectangle forces (3) to be a nonnegative perfect square.

Also, reducing (1) modulo 3 and using `n^3 == n (mod 3)` gives

```text
d == 0 (mod 3).                                  (4)
```

So every strictly concave mixed second difference of the 3x3 root array is a positive multiple of 3.

## 2. The whole 3x3 root array

Let the first row gaps be `h,j`, the first column gaps be `a,b`, and let the four adjacent mixed deficits be `d,e,f,g`.  Then every candidate root grid can be written

```text
r00 = x
r01 = x+h
r02 = x+h+j

r10 = x+a
r11 = x+a+h-d
r12 = x+a+h+j-d-e

r20 = x+a+b
r21 = x+a+b+h-d-f
r22 = x+a+b+h+j-d-e-f-g.
```

All nine cube values have Cartesian additive form `C_i+T_j` if and only if the four adjacent rectangles satisfy

```text
Q(x,       a,   h,   d) = 0,
Q(x+h,     a-d, j,   e) = 0,
Q(x+a,     b,   h-d, f) = 0,
Q(x+a+h-d, b-f, j-e, g) = 0,                    (5)
```

where `Q=0` is equation (2) moved to one side.

Thus the original problem is equivalent to finding positive integers

```text
x,a,b,h,j,d,e,f,g
```

with the obvious positivity/strict-order inequalities, with

```text
d,e,f,g positive multiples of 3,
```

satisfying the four quadratic equations (5), and with the resulting nine roots distinct.
The Latin placement from `r20` then reconstructs the semi-magic square.

This formulation has no finite-search assumption and no floating-point step.  It replaces the nine roots by one absolute root plus eight positive discrete increments, while making four divisibility constraints and four perfect-square discriminants explicit.
