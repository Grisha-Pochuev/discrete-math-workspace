# r53 — translation form of the local Vieta move

This note rewrites the r45/r47 Vieta involution directly in the four cube roots of one adjacent rectangle. It exposes the exact reason why the local descent sometimes returns to the positive cone and sometimes stops.

## 1. Physical rectangle and Hadamard coordinates

Let

```text
x   y
z   w
```

be positive integer roots with

```text
x^3 + w^3 = y^3 + z^3,
x < y,z < w,
d := y+z-x-w = 6k > 0.
```

Put `R=3k=d/2`. The r45 coordinates are equivalently

```text
C = (x+y+z+w)/2,
P = (-x-y+z+w)/2,
Q = (-x+y-z+w)/2,
R = (-x+y+z-w)/2.
```

Conversely

```text
x = (C-P-Q-R)/2,
y = (C-P+Q+R)/2,
z = (C+P-Q+R)/2,
w = (C+P+Q-R)/2.
```

Thus r45 is a Hadamard transform of the four roots (with `R=3k`).

## 2. The second root is a uniform translation

Let

```text
m = (y^2+z^2-x^2-w^2)/2 = R*C-P*Q.
```

Translate all four roots by the same rational number `t`. Direct expansion, using the original cube equality, gives the exact factorization

```text
F(t)
 = (x+t)^3 + (w+t)^3 - (y+t)^3 - (z+t)^3
 = -6 t (R t + m).
```

Hence there are exactly two translation parameters preserving the cube rectangle:

```text
t=0,
t=-m/R.
```

Set

```text
mu = m/R.
```

Then the nontrivial translated rectangle is

```text
x-mu, y-mu, z-mu, w-mu.
```

The r40 root bound becomes simply

```text
x < mu < w.
```

Therefore the nontrivial translation always crosses zero.

## 3. Exact link with the Vieta root

The r47 Vieta conjugate of `C` is

```text
C' = 2*P*Q/R - C.
```

Since `m=R*C-P*Q`,

```text
C'-C = -2m/R = -2mu.
```

Thus replacing `C` by `C'` is exactly the uniform root translation by `-mu`.

In particular, the translation is integral iff

```text
R | m,
```

or equivalently (because `m=R*C-P*Q`)

```text
R | P*Q.
```

This gives a sharper description of the arithmetic obstruction than merely saying that a Vieta root may fail to be integral.

## 4. When the translated signed rectangle becomes a smaller positive rectangle

Assume, after possibly interchanging the two coordinate directions, that

```text
y <= z,
P >= Q.
```

Because `x<mu<w`, there are only two relevant sign patterns:

1. `mu <= y`: only `x-mu` is negative;
2. `y < mu < z`: exactly `x-mu` and `y-mu` are negative.

(The case `mu >= z` cannot occur; it is equivalent to the positivity `C'>0` from r47.)

In the second case, if `mu` is an integer, move the two negative cubes to the opposite sides. Define

```text
X = mu-y,
Y = mu-x,
Z = z-mu,
W = w-mu.
```

Then all four are positive integers and

```text
X^3 + W^3 = Y^3 + Z^3.
```

Moreover `X<Y,Z<W`; this is another physical positive cube rectangle. In centered coordinates its triple is obtained from

```text
(C,P,Q;R)
```

by the Vieta replacement `C -> C'` followed by the permutation that makes `P` the new largest coordinate:

```text
(C_new,P_new,Q_new;R) = (P,C',Q;R)
```

when `C' >= Q`, with the last two entries interchanged otherwise.

The positivity re-entry condition has equivalent forms

```text
y < mu < z
<=>
0 < C' < P-Q-R.
```

Since the new largest centered coordinate is `P<C`, this is a strict positive descent.

## 5. Two genuine local stopping mechanisms

A physical integral cube rectangle therefore fails to descend by this move for exactly two conceptually different reasons:

- **arithmetic stop:** `mu=m/R` is not integral (`R` does not divide `P*Q`);
- **geometric stop:** `mu <= min(y,z)`, so the nontrivial translated rectangle has only one negative root and cannot be rearranged into a positive 2+2 cube equality by signs alone.

Both stops occur for primitive examples, so a proof of the 3x3 problem cannot claim that every local block descends. The remaining global target is sharper: prove that four blocks satisfying the r45 gluing relations cannot all be simultaneous stopping blocks, or find a global mutation that couples their Vieta moves.

## 6. Examples

A descending block:

```text
9^3 + 34^3 = 16^3 + 33^3.
```

Here `R=3`, `m=54`, hence `mu=18`. Translation gives

```text
(-9)^3 + 16^3 = (-2)^3 + 15^3,
```

and moving the negative cubes gives the strictly smaller block

```text
2^3 + 16^3 = 9^3 + 15^3.
```

A geometric stopping block is the classical

```text
1^3 + 12^3 = 9^3 + 10^3,
```

where `mu=6<9,10`.
