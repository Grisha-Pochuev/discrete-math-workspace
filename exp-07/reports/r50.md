# r50 explicit splitting of the three genus-2 factors

This note turns the final six complex elliptic dimensions of `r48-r49` into explicit equations over controlled cubic extensions.

## 1. Three rational genus-2 models

The three cyclic cubic quotients from `r49` are

```text
H0: Y^3=z^2(z+A)(z+B),
H1: Y^3=z(z+A)^2(z+B),
H2: Y^3=z(z+A)(z+B)^2.                           (1)
```

Each has a rational hyperelliptic model.

For `H0`, put

```text
v=Y/z.
```

Then

```text
v^3=z+A+B+AB/z,
```

so `z` satisfies a quadratic equation.  Its discriminant gives

```text
H0': W^2=v^6-2(A+B)v^3+(A-B)^2.                 (2)
```

For `H1`, put

```text
v=Y/(z+A).
```

Eliminating `z` gives

```text
H1': W^2=v^6+2(2A-B)v^3+B^2.                   (3)
```

For `H2`, put

```text
v=Y/(z+B),
```

and obtain

```text
H2': W^2=v^6+2(2B-A)v^3+A^2.                   (4)
```

Thus all three genus-2 factors have the common shape

```text
W^2=X^6+L X^3+D^2.                               (5)
```

## 2. The extra involution over a cubic field

Choose `s` with

```text
s^3=D.
```

Then (5) admits the involution

```text
X -> s^2/X,
W -> s^3 W/X^3.                                  (6)
```

The hyperelliptic involution changes only the sign of `W`.  Hence (6) and its composition with the hyperelliptic involution give the two genus-one quotients.

Put

```text
U=X+s^2/X.
```

Using

```text
X^3+s^6/X^3=U^3-3s^2U,                           (7)
```

and the exact factorizations

```text
U^3-3s^2U+2s^3=(U-s)^2(U+2s),
U^3-3s^2U-2s^3=(U+s)^2(U-2s),                   (8)
```

the two elliptic quotient curves are

```text
E_+ : V^2=(U+2s)(U^3-3s^2U+L),
E_- : V^2=(U-2s)(U^3-3s^2U+L).                  (9)
```

These quartics have genus one.  They are the two elliptic factors of the genus-2 Jacobian over the cubic field `Q(s)`.

## 3. The six factors for the fixed-layer curve

For the three rational genus-2 curves (2)-(4), use the following parameters.

### Factor pair coming from H0

```text
D0=A-B,
s0^3=A-B,
L0=-2(A+B).
```

Then

```text
E0,+ : V^2=(U+2s0)(U^3-3s0^2 U-2(A+B)),
E0,- : V^2=(U-2s0)(U^3-3s0^2 U-2(A+B)).         (10)
```

### Factor pair coming from H1

```text
D1=B,
s1^3=B,
L1=2(2A-B).
```

Then

```text
E1,+ : V^2=(U+2s1)(U^3-3s1^2 U+2(2A-B)),
E1,- : V^2=(U-2s1)(U^3-3s1^2 U+2(2A-B)).        (11)
```

### Factor pair coming from H2

```text
D2=A,
s2^3=A,
L2=2(2B-A).
```

Then

```text
E2,+ : V^2=(U+2s2)(U^3-3s2^2 U+2(2B-A)),
E2,- : V^2=(U-2s2)(U^3-3s2^2 U+2(2B-A)).        (12)
```

So the last six elliptic dimensions split over exactly the controlled cubic fields

```text
Q(cuberoot(A-B)),
Q(cuberoot(B)),
Q(cuberoot(A)).                                  (13)
```

No unspecified algebraic closure is needed to write the factor equations.

## 4. Arithmetic interpretation

The three cubic fields in (13) are attached to the same three basic coordinate differences

```text
A=b^3-a^3,
B=c^3-a^3,
B-A=c^3-b^3
```

that already control the first three rational Mordell elliptic quotients in `r48`.

Thus the entire genus-10 closure problem is organized by the arithmetic of exactly these three repeated differences:

- four elliptic quotients are defined over `Q`;
- three genus-2 factors are defined over `Q`;
- each genus-2 factor splits explicitly into two elliptic curves after adjoining one cube root of one of `A`, `B`, `A-B`.

This gives explicit equations for all ten elliptic dimensions of the generalized-Fermat decomposition.

Exact algebraic certificate: `exp-07/src/r50.py`.

The existence of the genus-2 splitting is consistent with Carvacho--Hidalgo--Quispe, Section 6.3; the present formulas keep track of the arithmetic cubic extensions for the rational twist relevant here.
