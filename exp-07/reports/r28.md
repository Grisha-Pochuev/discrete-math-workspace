# r28 mixed-deficit determinant

This note gives a global inequality coupling the four adjacent `2x2` root deficits from `r27`.

## 1. Root grid as a concave additive surface

Use the Cartesian additive cube grid from `r20`:

```text
r_ij = (A_i + B_j)^(1/3),
A0 < A1 < A2,
B0 < B1 < B2.
```

For adjacent intervals define the positive mixed deficits

```text
d = r01+r10-r00-r11,
e = r02+r11-r01-r12,
f = r11+r20-r10-r21,
g = r12+r21-r11-r22.
```

These are exactly the variables `d,e,f,g` in `r27`.

For `F(t)=t^(1/3)`, since

```text
-F''(t) = (2/9) t^(-5/3),
```

an adjacent deficit has the exact integral representation

```text
Delta(I,J) = integral_I integral_J K(u,v) dv du,
K(u,v) = (2/9)(u+v)^(-5/3).
```

Thus `d,e,f,g` are the four integrals of the same positive kernel over the four Cartesian products

```text
I0 x J0, I0 x J1,
I1 x J0, I1 x J1,
```

where every point of `I0` is smaller than every point of `I1`, and likewise for `J0,J1`.

## 2. Strict TP2 inequality

Take

```text
u < U,
v < V.
```

Then

```text
(u+V)(U+v) - (u+v)(U+V)
  = (U-u)(V-v) > 0.
```

Therefore

```text
(u+v)(U+V) < (u+V)(U+v).
```

Raising both positive sides to the power `-5/3` reverses the inequality, so

```text
K(u,v) K(U,V) > K(u,V) K(U,v).              (1)
```

Now write the products `d*g` and `e*f` as fourfold integrals over

```text
u in I0, U in I1, v in J0, V in J1.
```

Their integrand difference is exactly the left side minus the right side of (1), which is strictly positive everywhere.  Hence

```text
d*g > e*f.                                   (2)
```

This is a strict global condition; it does not follow by applying the four rectangle equations independently.

## 3. Integer strengthening

By `r27`, each adjacent deficit is a positive multiple of 6:

```text
d,e,f,g in 6 Z_{>0}.
```

Consequently

```text
d*g - e*f
```

is a positive multiple of 36.  Combining with (2):

```text
d*g - e*f >= 36.                             (3)
```

Equivalently,

```text
d/e > f/g
```

(and `d/f > e/g`).

So any future root-gap search may reject a candidate as soon as its four mixed deficits fail (3).

Exact algebra for the pointwise kernel determinant is checked in `exp-07/src/r28.py`; the integral step above is the proof of the passage from the kernel to the four discrete deficits.
