# r20 reduction note

This note records an exact structural reduction used by the current search.  It makes no global finite-search claim.

## 1. Linear normal form

Let the nine cell values (not their cube roots) be

```text
a b c
d e f
g h i
```

and suppose the three row sums and three column sums are all equal.  Taking `a,e,f,h,i` as free values, the four independent linear constraints give

```text
b = f+i-a,
c = e+h-a,
d = h+i-a,
g = e+f-a.
```

Put

```text
B0 = a,
B1 = h,
B2 = f,
U  = e-a,
V  = i-a.
```

Then every 3x3 semi-magic array has the form

```text
B0      B2+V    B1+U
B1+V    B0+U    B2
B2+U    B1      B0+V
```

and every row and column has sum

```text
B0+B1+B2+U+V.
```

Thus the nine entries are exactly the Cartesian additive grid

```text
{B0,B1,B2} + {0,U,V},
```

with a fixed Latin placement.

## 2. Positive normalization

If all nine entries are positive cubes, all three layers corresponding to offsets `0,U,V` consist of cubes.  Reorder the three offsets as

```text
t0 < t1 < t2
```

and replace the base values by

```text
Ck = Bk+t0.
```

The same set of nine cube values is then

```text
{C0,C1,C2} + {0,D,E},
D=t1-t0 > 0,
E=t2-t0 > D.
```

Consequently every sought solution implies three distinct positive cube roots `x0,x1,x2` and two distinct positive shifts `D,E` such that

```text
xk^3 + D is a cube,
xk^3 + E is a cube
```

for each `k=0,1,2`.

In particular `D` is a positive difference of cubes in at least three ways, with lower endpoints `x0,x1,x2`.

## 3. Exact closure of a base triple

Assume `a<b<c` are the three lower cube roots for a fixed positive shift `D`.

Any second positive common shift `E` gives roots `p,q,r` with

```text
p^3-a^3 = q^3-b^3 = r^3-c^3 = E.
```

Subtracting the first two equations yields

```text
q^3-p^3 = b^3-a^3.                 (1)
```

Therefore every possible `E` is obtained by enumerating all positive representations `(p,q)` of the single fixed difference `b^3-a^3`, setting

```text
E = p^3-a^3,
```

and testing whether `c^3+E` is a cube.  Conversely, any `(p,q)` satisfying (1), with `E>0` and `c^3+E=r^3`, gives the required two common shifts.  No external table for the second shift is needed.

This is exactly the closure step implemented in `d1.cpp` / `d2.cpp` and independently re-exposed by `r19.cpp`.
