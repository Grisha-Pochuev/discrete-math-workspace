# r22 bidirectional repeated-difference lemma

This note records an exact necessary condition for any positive distinct 3x3 semi-magic cube solution.  It is a consequence of the universal additive-grid normal form in `r20.md` and does not depend on a parametrized subfamily.

## 1. Setup

By `r20`, after ordering the two coordinate directions, every sought solution can be written at the level of cube values as

```text
{X0, X1, X2} + {0, D, E},
```

where

```text
0 < D < E
```

and all nine sums are distinct positive cubes.  Write their positive cube roots as

```text
xi^3 = Xi,
yi^3 = Xi + D,
zi^3 = Xi + E,
```

and order

```text
x0 < x1 < x2.
```

The same order then holds in the other two layers:

```text
y0 < y1 < y2,
z0 < z1 < z2.
```

## 2. Three representations in the transverse direction

For every pair `i<j`, subtraction of the layer equations gives the exact identity

```text
xj^3 - xi^3 = yj^3 - yi^3 = zj^3 - zi^3.       (1)
```

Hence each of the three positive transverse differences

```text
K01 = x1^3-x0^3,
K12 = x2^3-x1^3,
K02 = x2^3-x0^3
```

has at least three positive representations as a difference of cubes.  The three representations for `Kij` are

```text
(xi,xj), (yi,yj), (zi,zj).
```

They are distinct because all nine roots are pairwise distinct.

Thus a triple of representations of a candidate shift `D` cannot belong to a solution unless **all three pairwise cube differences between its lower endpoints are themselves differences of positive cubes in at least three ways**.

This is an exact necessary filter.  It may be applied before the more expensive closure test.

## 3. Transposition symmetry

The same nine cube values can be viewed with the two additive coordinates interchanged.  In that orientation the base layer is

```text
{x0^3, y0^3, z0^3}
```

and the two positive offsets are

```text
K01 < K02.
```

Therefore the exact `d1/d2` search is not merely applicable to the original smaller offset `D`; it is equally applicable to the smaller transverse offset `K01`.

Consequently, if an exact contiguous `d2` frontier excludes every normalized smaller offset through `F`, then any still-possible solution must satisfy simultaneously

```text
D   > F,
K01 > F.                                          (2)
```

With the currently verified frontier from `r20`,

```text
F = 12,000,000,000,000,000,000,
```

so both independent coordinate directions of any solution must already exceed this bound.

## 4. Computational use

For a fixed repeated difference `D` and three of its representations

```text
(a,A), (b,B), (c,C),   a<b<c,
```

form

```text
Kab=b^3-a^3,
Kbc=c^3-b^3,
Kac=c^3-a^3.
```

Before attempting the second-shift closure, reconstruct the positive representations of all three `K` values exactly and reject the triple unless every multiplicity is at least three.

The existing closure remains complete: enumerate all positive representations `(p,q)` of `Kab`, set

```text
T = p^3-a^3,
```

and test whether `c^3+T` is a cube.  The new condition only removes triples that cannot possibly close; it does not remove any solution.

`src/r22.cpp` measures this filter on independently reconstructed repeated-difference groups and exactly replays any surviving closure.
