# r38 propagation through all nine rectangles

The `r27` equations use the four adjacent `2x2` rectangles, but the Cartesian additive cube grid has the equal-sum property for every choice of two root rows and two root columns. There are nine such rectangles. Applying the inert-prime support lemma `r34` to the five non-adjacent rectangles strengthens the global restrictions.

Write

```text
d=6k0, e=6k1, f=6k2, g=6k3.
```

## 1. Rectangle deficit parameters

The nine row-interval / column-interval choices have local `k` parameters

```text
rows 01, cols 01:  k0
rows 01, cols 12:  k1
rows 12, cols 01:  k2
rows 12, cols 12:  k3
rows 01, cols 02:  k0+k1
rows 12, cols 02:  k2+k3
rows 02, cols 01:  k0+k2
rows 02, cols 12:  k1+k3
rows 02, cols 02:  k0+k1+k2+k3.
```

This follows by telescoping the mixed root deficits over the relevant block.

## 2. Elementary vertical strips

The three vertical root gaps between root rows 0 and 1 are

```text
A0=a,
A1=a-d,
A2=a-d-e.
```

Let `ell` be an odd prime with `ell == 2 (mod 3)`.

If `ell | A0`, the rectangle on columns `01` forces `ell | k0`, while the large rectangle on columns `02` forces `ell | k0+k1`; hence `ell | k1`. If `ell | A1`, the two adjacent rectangles directly force `ell | k0` and `ell | k1`. The case `ell | A2` is symmetric. Therefore

```text
ell | A0*A1*A2  => ell | gcd(k0,k1).             (1)
```

For the lower vertical strip

```text
B0=b,
B1=b-f,
B2=b-f-g,
```

the same argument gives

```text
ell | B0*B1*B2  => ell | gcd(k2,k3).             (2)
```

## 3. Elementary horizontal strips

For the first horizontal interval across the three root rows,

```text
H0=h,
H1=h-d,
H2=h-d-f,
```

we obtain

```text
ell | H0*H1*H2  => ell | gcd(k0,k2).             (3)
```

For the second horizontal interval,

```text
J0=j,
J1=j-e,
J2=j-e-g,
```

we obtain

```text
ell | J0*J1*J2  => ell | gcd(k1,k3).             (4)
```

## 4. The two long strips

The vertical root gaps spanning root rows 0 and 2 are

```text
C0=a+b,
C1=a+b-d-f,
C2=a+b-d-e-f-g.
```

Their two adjacent column rectangles have parameters `k0+k2` and `k1+k3`, while the full corner rectangle has parameter `k0+k1+k2+k3`. Hence

```text
ell | C0*C1*C2
 => ell | gcd(k0+k2, k1+k3).                     (5)
```

Similarly, the horizontal root gaps spanning columns 0 and 2 are

```text
L0=h+j,
L1=h+j-d-e,
L2=h+j-d-e-f-g,
```

and

```text
ell | L0*L1*L2
 => ell | gcd(k0+k1, k2+k3).                     (6)
```

## 5. Six simultaneous support constraints

Every odd inert prime factor of the six three-gap strips is therefore accounted for by one of the six gcds

```text
gcd(k0,k1),
gcd(k2,k3),
gcd(k0,k2),
gcd(k1,k3),
gcd(k0+k2,k1+k3),
gcd(k0+k1,k2+k3).                                (7)
```

In particular, whenever one of these gcds equals `1`, the corresponding entire three-gap strip contains no odd prime factor congruent to `2 modulo 3`.

This strengthens `r34`, where only the middle shared gaps were forced into neighboring gcds. The large rectangles force the same restriction on both end gaps as well.

All statements are exact consequences of applying `r34` to all nine equal-sum cube rectangles; no finite search is used.
