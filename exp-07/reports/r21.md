# r21 — exact gap-ratio lemma

This note records a necessary condition for every positive two-shift cube grid from the r20 reduction.

Let a base cube root be `x>0`.  Suppose two common positive offsets `0<D<E` give

```text
D = (x+h)^3 - x^3,
E = (x+k)^3 - x^3,
```

with positive integer root increments `h<k`.  Put

```text
t = x/h,
lambda = k/h.
```

Then

```text
D = h^3 (3t^2+3t+1)
```

and

```text
E/D = R(t,lambda)
     = lambda (3t^2+3 lambda t+lambda^2)/(3t^2+3t+1).
```

Exact differentiation gives

```text
dR/dt =
 -3 lambda(lambda-1)(3t^2+2t+2 lambda t+lambda)
 ------------------------------------------------,
              (3t^2+3t+1)^2
```

which is strictly negative for `t>0, lambda>1`, while

```text
dR/dlambda = 3(lambda+t)^2/(3t^2+3t+1) > 0.
```

## Consequence for any candidate square

For the three lower roots in the r20 normalisation, order

```text
x1 < x2 < x3.
```

Let `hi` be the root increment for the smaller common offset `D`, and `ki` the increment for the larger common offset `E`.

For fixed positive `D`, the function

```text
h(3x^2+3xh+h^2)
```

is strictly increasing in both `x` and `h`.  Therefore

```text
h1 > h2 > h3.
```

Hence

```text
t1=x1/h1 < t2=x2/h2 < t3=x3/h3.
```

All three pairs satisfy the same equation

```text
R(ti,lambda_i)=E/D,
lambda_i=ki/hi>1.
```

Since `R` decreases strictly with `t` and increases strictly with `lambda`, equality of `R` forces

```text
k1/h1 < k2/h2 < k3/h3.                 (1)
```

The increments for the larger fixed shift also decrease:

```text
k1 > k2 > k3.
```

Thus every solution must exhibit the rigid pattern

```text
h1 > h2 > h3 > 0,
k1 > k2 > k3 > 0,
k1/h1 < k2/h2 < k3/h3.
```

Equivalently, the adjacent integer determinants satisfy

```text
k2*h1-k1*h2 >= 1,
k3*h2-k2*h3 >= 1.
```

## Immediate exclusion of proportional gap patterns

If the two increment triples were proportional,

```text
ki = lambda hi
```

with one common `lambda>1`, then all three ratios `ki/hi` would be equal, contradicting (1).  Therefore no sought square can have proportional root-increment triples.

## Additional exact bounds

The certificate also factors

```text
R-lambda
 = lambda(lambda-1)(lambda+3t+1)/(3t^2+3t+1) > 0,
```

and

```text
lambda^3-R
 = 3 lambda t(lambda-1)(lambda t+lambda+t)/(3t^2+3t+1) > 0.
```

Hence, for every one of the three bases,

```text
(E/D)^(1/3) < ki/hi < E/D.             (2)
```

All statements are exact.  Symbolic checker: `exp-07/src/r21.py`.
