# r33 mod-49 sharpening

This note improves only the `7`-adic part of the universal modular divisor from `r32`.

Use the same additive cube grid and Vandermonde products

```text
VA=(A1-A0)(A2-A0)(A2-A1),
VB=(B1-B0)(B2-B0)(B2-B1).
```

All nine values `Ai+Bj` are integer cubes.

## Exact mod-49 minimum

Modulo

```text
49=7^2
```

there are exactly 15 cube residues.  Translation lets us normalize `A0=0` without changing any coordinate difference.

The finite exact certificate `src/r33.py` enumerates every normalized residue configuration compatible with all nine sums being cube residues.  For each pair of residues equal modulo 49 it counts a guaranteed `7`-adic valuation of at least 2; for a nonzero difference it uses its exact valuation below 2.

The exact minimum is

```text
v7(VA*VB) >= 4.                                  (1)
```

This is sharp already at the residue level; the certificate records a witness attaining valuation 4.

Thus `r32` can be sharpened from the factor `7^2` to

```text
7^4.
```

Combining with the already exact lower bounds

```text
v2 >= 6,
v3 >= 6,
v13 >= 2
```

gives the universal divisor

```text
2^6 * 3^6 * 7^4 * 13^2
 = 18,931,558,464.                                (2)
```

Therefore every candidate satisfies

```text
18,931,558,464 |
D*E*(E-D)*K01*K02*K12.                            (3)
```

The condition is independent of the size of the roots and independent of the finite exact frontier.

Exact finite certificate: `exp-07/src/r33.py`.
