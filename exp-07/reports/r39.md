# r39 square-deficit measure

This note identifies the square root hidden in the `r27/r29` discriminant and shows that it supplies a second additive, strictly totally-positive integer measure on the four adjacent rectangles.

## 1. One rectangle

Write an adjacent root rectangle as

```text
x   y=x+h
z=x+a   w=x+a+h-d
```

with

```text
x^3+w^3=y^3+z^3,
0<d<min(a,h).
```

The positive integer `m` from `r29` was

```text
m=d(x+a+h-d/2)-a*h.
```

Direct expansion gives the much simpler identity

```text
m = (y^2+z^2-x^2-w^2)/2.                         (1)
```

Thus `2m` is the mixed deficit of the **squares of the cube roots**.

The square relation of `r29` is equivalently

```text
m^2 = a*h*(a-d)*(h-d) - d^4/12.                  (2)
```

For an exact cube rectangle, (2) follows from (1); algebraically the difference between the two sides of (2) is `-d/3` times the cube-rectangle residual.

## 2. Additivity

Mixed differences telescope.  Therefore, if two adjacent rectangles are joined horizontally, their `m` values add exactly.  If their local values are `m0,m1`, the rectangle spanning both has

```text
m02=m0+m1.                                        (3)
```

The same holds vertically.  Consequently the nine rectangles of `r38` have `m` parameters

```text
m0, m1, m2, m3,
m0+m1,
m2+m3,
m0+m2,
m1+m3,
m0+m1+m2+m3,                                    (4)
```

in exact parallel with the corresponding `k` parameters.

## 3. Integral kernel

At cube-value level write

```text
r_ij=(Ai+Bj)^(1/3).
```

Then the squared roots are

```text
G(Ai+Bj),
G(t)=t^(2/3).
```

Since

```text
-G''(t)/2 = (1/9)t^(-4/3),
```

the local integer `m` has the exact integral representation

```text
m = integral_I integral_J (1/9)(u+v)^(-4/3) dv du. (5)
```

The kernel in (5) is strictly `TP2`: for `u<U` and `v<V`,

```text
(u+v)^(-4/3)(U+V)^(-4/3)
 > (u+V)^(-4/3)(U+v)^(-4/3).                     (6)
```

The proof is the same positive cross-product argument as in `r28` and `r36`.

## 4. A second integer determinant

Apply (6) to the four adjacent cube-coordinate rectangles.  Their positive integer `m` values satisfy

```text
m0*m3 > m1*m2.                                    (7)
```

Hence

```text
m0*m3-m1*m2 >= 1.                                 (8)
```

The candidate therefore carries two different positive integer `2x2` determinant constraints:

```text
k0*k3-k1*k2 >= 1,                                 (r28)
m0*m3-m1*m2 >= 1.                                 (r39)
```

The `k` matrix integrates the kernel `(1/27)(u+v)^(-5/3)`, while the `m` matrix integrates the less singular kernel `(1/9)(u+v)^(-4/3)`.  Their simultaneous arithmetic compatibility is a new target for the next reduction.
