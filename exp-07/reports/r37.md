# r37 contraction-ratio norm law

This note gives an exact arithmetic restriction on every adjacent cube rectangle and propagates it through the full `3x3` root grid.

## 1. One rectangle

Write a strictly ordered adjacent rectangle as

```text
x   y
z   w
```

with positive integer roots and

```text
x^3+w^3 = y^3+z^3.
```

Let the vertical outer and inner root gaps be

```text
A=z-x,
U=w-y,
```

so in the `r27` notation

```text
A=a,
U=a-d,
0<U<A.
```

Put

```text
lambda = U/A,
0<lambda<1.
```

Define rational numbers

```text
gamma = (y-lambda*x)/(1-lambda^3),
r = x/gamma-lambda^2,
s = z/gamma-lambda^2.
```

Then the four roots are reconstructed exactly as

```text
x = gamma(r+lambda^2),
y = gamma(lambda*r+1),
z = gamma(s+lambda^2),
w = gamma(lambda*s+1).
```

Direct factorization gives

```text
x^3+w^3-y^3-z^3
 = -gamma^3(lambda-1)(r-s)(lambda^2+lambda+1)
   (r^2+r*s+s^2-3lambda).
```

The rectangle is nondegenerate, so

```text
r^2+r*s+s^2 = 3lambda.                            (1)
```

Thus

```text
lambda = (r^2+r*s+s^2)/3.                         (2)
```

This is the quadratic norm form of the Eisenstein field.  Indeed, if `omega^2+omega+1=0`,

```text
r^2+r*s+s^2 = Norm(r-s*omega),
3 = Norm(1-omega).
```

Hence `lambda` itself is a rational norm.

## 2. Parity of inert-prime valuations

Let `p` be any prime with

```text
p == 2 (mod 3),
```

including `p=2`.

For odd such `p`, the form

```text
R^2+R*S+S^2
```

has `p`-adic valuation exactly twice the common extracted valuation of `R,S`, because its discriminant `-3` is a quadratic nonresidue modulo `p`.  For `p=2`, after removing the common power of 2, the three nonzero parity pairs `(1,0),(0,1),(1,1)` all make the form odd.

Therefore every rational value of the norm in (2) has even `p`-adic valuation.  Since `3` is not such a prime,

```text
v_p(lambda) is even.                              (3)
```

Recalling `lambda=U/A`,

```text
v_p(U) == v_p(A) (mod 2).                         (4)
```

So the inward and outward root gaps of a cube rectangle have the same valuation parity at every inert prime `p == 2 (mod 3)`.

By transposing the rectangle, the same holds for the horizontal gap ratio:

```text
v_p(w-z) == v_p(y-x) (mod 2).                     (5)
```

## 3. Propagation through the full root grid

In `r27`, the two vertical gap triples are

```text
(a,       a-d,       a-d-e),
(b,       b-f,       b-f-g),
```

and the two horizontal gap triples are

```text
(h,       h-d,       h-d-f),
(j,       j-e,       j-e-g).
```

Applying (4)-(5) to adjacent rectangles gives, for every prime `p == 2 (mod 3)`,

```text
v_p(a) == v_p(a-d) == v_p(a-d-e)        (mod 2),
v_p(b) == v_p(b-f) == v_p(b-f-g)        (mod 2),
v_p(h) == v_p(h-d) == v_p(h-d-f)        (mod 2),
v_p(j) == v_p(j-e) == v_p(j-e-g)        (mod 2).    (6)
```

Thus inert-prime valuation parity is conserved along each complete three-gap strip of the ordered root grid.

This condition is independent of the strict ratio inequalities of `r36` and the support restrictions of `r34-r35`, so all of them may be imposed simultaneously.
