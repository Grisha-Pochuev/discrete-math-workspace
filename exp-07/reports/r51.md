# r51 three geometric elliptic types

This note compresses the complete genus-10 elliptic decomposition of `r48-r50` to three geometric isomorphism types.

## 1. The normalized genus-2 factor

For the generalized Fermat parameter

```text
lambda=B/A,
```

Carvacho--Hidalgo--Quispe identify the three genus-2 quotients, over an algebraic closure, with a common genus-2 curve.  After the symmetric normalization used in `r50`, it may be written

```text
Y^2=X^6-c X^3+1,                                 (1)
```

where

```text
c=2(lambda+1)/(lambda-1).                        (2)
```

The two elliptic quotients are

```text
E_+ : V^2=(U+2)(U^3-3U-c),
E_- : V^2=(U-2)(U^3-3U-c).                      (3)
```

## 2. Binary-quartic invariants

For a quartic

```text
f(U)=aU^4+bU^3+c2 U^2+dU+e,
```

use the classical invariants

```text
I=12ae-3bd+c2^2,
J=72ac2e+9bc2d-27ad^2-27b^2e-2c2^3.
```

Its genus-one `j` invariant is

```text
j=6912 I^3/(4I^3-J^2).                           (4)
```

For the two quartics (3), exact calculation gives

```text
I_+ = -9(2c-5),
J_+ = -27(c^2-14c+22),
4I_+^3-J_+^2 = -729(c-2)(c+2)^3,

I_- = 9(2c+5),
J_- = -27(c^2+14c+22),
4I_-^3-J_-^2 = -729(c-2)^3(c+2).                 (5)
```

Substituting (2) into (4) yields the simple rational functions

```text
j_+(lambda)
 = -27 (lambda-9)^3 (lambda-1) / lambda^3,       (6)

j_-(lambda)
 = -27 (lambda-1) (9lambda-1)^3 / lambda.        (7)
```

They satisfy the symmetry

```text
j_-(lambda)=j_+(1/lambda).                       (8)
```

## 3. The full genus-10 decomposition

The four elliptic quotients in `r49` are generalized Fermat cubics of type `(3,2)`, hence all have

```text
j=0
```

over an algebraic closure.

Each of the three genus-2 factors contributes one copy of the geometric type `E_+` and one copy of `E_-`.  Consequently the full Jacobian has the geometric isogeny shape

```text
J(C_{A,B})
 ~ E_0^4 x E_+(lambda)^3 x E_-(lambda)^3,        (9)
```

where

```text
j(E_0)=0,
j(E_+)=j_+(lambda),
j(E_-)=j_-(lambda).                               (10)
```

Thus ten elliptic dimensions collapse to only three geometric `j`-types with multiplicities

```text
4,3,3.                                            (11)
```

## 4. Physical range

For a positive ordered base layer

```text
a<b<c
```

we have

```text
lambda=(c^3-a^3)/(b^3-a^3)>1.                   (12)
```

In this range

```text
j_-(lambda)<0
```

always, while `j_+` changes sign at

```text
lambda=9.
```

The special value `lambda=9` makes

```text
j_+=0,                                           (13)
```

so one of the two variable elliptic types merges geometrically with the four fixed `j=0` factors.  This marks a potentially useful high-symmetry subfamily, though existence of a nontrivial positive rational base triple with `lambda=9` is a separate arithmetic question.

## 5. Arithmetic caution

Equation (9) is a geometric statement.  Over `Q`, the four `j=0` factors and the three genus-2 abelian surfaces occur as rational twists described in `r49-r50`.  Rational `j` invariants (6)-(7) identify the geometric elliptic types but do not by themselves identify the exact rational twists or prove that all ten quotient maps descend individually to `Q`.
