# Run 000

## Execution

- 20 jobs.
- 4 independent workers per job.
- 19,800 seconds of compute per job.
- 360-minute job timeout.
- Manual launch only after smoke validation.

## Work partition

- Four target classes.
- Five jobs per class.
- Four workers per job.
- Deterministic block-cyclic partitioning.
- Checkpoint after each completed block.

## Search requirements

- Generate target data exactly from committed source.
- Use exact arithmetic for all acceptance decisions.
- Use modular prefilters before expensive exact work.
- Reconstruct every surviving record from the original constraints before acceptance.
- Verify accepted records independently.

## Smoke requirement

One runner, four workers, no more than 10 minutes. Validate generation, filtering, exact solver path, checkpoint/resume, collection, memory use, and throughput.

## Artifacts

Record source SHA, target ID, worker ID, completed block IDs, counters, accepted records, machine diagnostics, dependency versions, and failure state.

The collector must distinguish completed coverage from missing/failed coverage.
